Methodology / Approach
Fig 1: High Level
Overview of the
UMAP Peptide
Embedding Pipeline
This pipeline enables exploration of structural patterns in peptide embeddings and comparison of antimicrobial vs non-antimicrobial sequences. The app visualises pre-computed ProteoGPT peptide embeddings using two linked projections: a flat 2D UMAP scatter and a 3D unit-sphere visualization derived from normalized n-dimensional UMAP embeddings. Optuna-optimized hyperparameters are stored and loaded per target dimensionality (2D–8D). The following challenges were addressed during development:
  • Trustworthiness scores were sensitive to hyperparameter choices (e.g., n_neighbors, min_dist), requiring per-dimension validation
  • n-dimensional UMAP output required explicit L2 normalization before sphere projection to avoid geometric distortion
  • Streamlit reruns reset plot state — 2D selections are persisted via session_state so the 3D sphere stays in sync
To address the parameter-consistency issue, we switched from manually-tuned values to JSON files produced by Optuna, one per target dimensionality, so each run uses validated hyperparameters rather than arbitrary defaults. The two UMAP runs (2D flat + nD sphere) share n_neighbors, min_dist, metric, and method, ensuring the linked views are directly comparable.
